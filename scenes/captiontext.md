## ch01 从「门」到「带」

[ch01_gate]
上一支视频里，数列的 N 是一道门

[ch01_right_only]
n 只能增大，所以一个数就够用了

[ch01_both_sides]
但 x 可以从左边逼近，也可以从右边逼近

[ch01_band_not_gate]
两边都得关注——这就是为什么 δ 是一条「带」，不是一道「门」

## ch02 ε 带登场

[ch02_concrete]
先看一个具体的：f(x) = x^2，在 x_0 = 1 附近

[ch02_distance]
x 越靠近 1，纵坐标就越靠近 1——还是「距离」那件事

[ch02_give_eps]
先给一个误差上限 ε，比如 ε = 0.8

[ch02_requirement]
要求：只要 x 离 1 够近，f(x) 就必须落在这条带里

## ch03 δ 带登场

[ch03_look_x_axis]
现在看横轴：x 要离 1 多近，才能够让f(x)都落到带里？

[ch03_strip_definition]
这条竖带，就是 δ：左右各伸出 δ，把 x_0 夹在正中间

[ch03_the_gap]
注意中间这条缝：x 不许等于 x_0，只能「靠近」

## ch04 初步合格 + 发现失控

[ch04_verify]
拿 δ = 0.6 去验一下：带里的曲线，是不是都在绿带里？

[ch04_right_out]
右边跑出去了：f(1.6) = 2.56，比上限 1.8 高得多

[ch04_left_out]
左边也跑出去了：f(0.4) = 0.16，比下限 0.2 还低

[ch04_must_shrink]
两边同时溢出，那么δ 必须收窄

## ch05 δ 被逼窄

[ch05_shrink_intro]
把 ε 一档档收窄，看 δ 被逼到哪里

[ch05_ok_034]
δ 收到 0.34，重新守住

[ch05_fail_eps03]
ε 收到 0.3——刚够用的 δ = 0.34 立刻失效

[ch05_ok_014]
δ 收到 0.14，重新守住

[ch05_fail_eps015]
ε 收到 0.15——刚够用的 δ = 0.14 立刻失效

[ch05_ok_007]
δ 收到 0.07，重新守住

[ch05_summary]
ε 每降一档，δ 就被逼窄一层——上一轮刚够用的 δ 总会失效

## ch06 0 < 的深意

[ch06_why_zero]
反过来问：为什么定义里非要写 0 < |x - x_0| 而不是 0 ≤ |x - x_0|？

[ch06_undefined]
这个函数在 x = 1 处根本没有定义——分母是 0

[ch06_both_sides_approach]
但 x 从两边靠近 1 时，函数值都在靠近 2

[ch06_process_not_point]
所以极限看的是「靠近的过程」，不是「那一点本身」

[ch06_punctured_meaning]
这就是 0 < |x - x_0| 的全部意思：考虑的只是「去心邻域」

## ch07 左右极限

[ch07_from_which_side]
再看一件数列那里没有的事：x 从哪边来

[ch07_left_one_right_three]
这个函数，从左边过来停在 1，从右边过来停在 3

[ch07_no_limit]
两个答案不同，所以这个函数在 1 处没有极限

[ch07_both_sides_required]
所以 δ 带必须左右两边同时把曲线压进 ε 带

## ch08 通式 —— δ 怎么找

[ch08_what_is_delta]
那 δ 具体是多少？回到 f(x) = x^2 自己看

[ch08_shrunk_in]
δ 窄到一定程度，带里的曲线就整个缩进绿带里了

[ch08_fixed_recipe]
其实找 δ 有固定套路

[ch08_result]
δ = ε/3：ε 给我，δ 就定了——这是算出来的，不是猜的

[ch08_sync]
ε 小 10 倍，δ 就跟着小 10 倍——同步退让

## ch09 定义收束

[ch09_translate]
把刚才做的事，翻译成一句数学语言

[ch09_first]
第一句：你给多小的 ε 都行

[ch09_second]
第二句：我总能找到一条 δ 窄带

[ch09_third]
第三句：窄带里的每个 x，都达标

[ch09_same_as_sequence]
回头看，它说的和数列极限是一回事

[ch09_gate_to_band]
只是「门」变成了「带」，「往右走」变成了「两边都来」

[ch09_closing]
你随便说多小的误差，我都能圈出够小的一块——这就是极限
